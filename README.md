# AI Agent for Data Science 🚀

An AI-powered Data Science Assistant that automates data cleaning, exploratory data analysis (EDA), visualization, machine learning model selection, predictions, and smart insights for faster and smarter decision-making.

---

## 📌 Overview

The **AI Agent for Data Science** project is designed to simplify complex data science workflows using intelligent automation. It enables users to upload datasets, analyze data, generate visualizations, build machine learning models, and receive AI-driven recommendations through an interactive interface.

This project helps reduce manual effort and makes data science more accessible for students, analysts, researchers, and businesses.
