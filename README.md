AI Agent for Data Science

An intelligent AI-powered Data Science Assistant built to automate data analysis, preprocessing, visualization, and machine learning workflows. This project helps users upload datasets, perform exploratory data analysis (EDA), generate insights, build predictive models, and receive smart recommendations using AI-driven decision-making.

🚀 Features
Automated Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Smart Data Visualization & Charts
Machine Learning Model Selection
Prediction & Performance Evaluation
AI-based Insights and Recommendations
Interactive User-Friendly Interface
Real-time Report Generation

⚙️ Installation
1. Clone the Repository
git clone <your-repository-link>
cd ai-agent-data-scientist
2. Create Virtual Environment
python -m venv venv
3. Activate Virtual Environment
Windows
venv\Scripts\activate
Mac/Linux
source venv/bin/activate
4. Install Dependencies
pip install -r requirements.txt
▶️ Run the Project
streamlit run app.py

The application will open in your browser.
